# 🕵️ OSINT & Reconnaissance

| Tool | Link | Usage / Notes |
| :--- | :--- | :--- |
| **Reverse Image Search** | [Yandex](https://yandex.com/images/)<br>[Google Images](https://images.google.com)<br>[Duplicheck](https://www.duplichecker.com/reverse-image-search.php) | Upload an image to find where else it exists on the web. Yandex is best for facial recognition. |
| **Waypoints** | [OpenNav](https://opennav.com/) | Find marine and aviation waypoints. |
| **Decimal to IP** | [Browserling](https://www.browserling.com/tools/dec-to-ip) | Convert integer IPs (e.g., 2130706433) to standard (127.0.0.1). |
| **Public Wifi** | [Wigle](https://wigle.net/)<br>[Wifi Map](https://www.wifimap.io/) | Global map of wireless networks. Useful for geolocation challenges. |
| **IP Information** | [XMyIP](https://xmyip.com/)<br>[WhoIs](https://who.is/) | standard `whois` lookup for domain registration info. |
| **MRZ (Passport)** | [GlobalPass AG](https://globalpass.ch/mrz-check/)<br>[Wikipedia Guide](https://en.wikipedia.org/wiki/Machine-readable_passport) | Decode the "Machine Readable Zone" on passports. |
| **QR Codes** | [QR Code Raptor](https://qrcoderaptor.com/)<br>[Inlite](https://online-barcode-reader.inlite.com/) | Decode damaged or complex QR/Barcodes. |
| **Geolocation** | [Google Lens](https://lens.google.com/)<br>[What3Words](https://what3words.com/) | Identify landmarks from photos or convert 3-word addresses to coords. |
